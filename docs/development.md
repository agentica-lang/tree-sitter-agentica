# Development

Run commands from the repository root. `tree-sitter-cli` is pinned in the npm lockfile, so no global installation is needed.

```sh
npm ci
npx tree-sitter generate                # rebuild src/parser.c from grammar.js
npx tree-sitter test                    # run test/corpus/
npx tree-sitter build -o agentica.so    # build a shared library
npx tree-sitter parse file.agc          # print one syntax tree
```

## Repository layout

- `grammar.js`: the grammar definition.
- `src/scanner.c`: the external scanner; see [grammar details](grammar.md#external-scanner).
- `Cargo.toml`, `bindings/rust/`: the Rust crate; `cargo test` runs its doc test.
- `src/parser.c`, `src/grammar.json`, `src/node-types.json`: generated by `tree-sitter generate` and committed.
- `queries/`: highlights, tags, and locals queries.
- `test/corpus/`: parser corpus tests, organized by area.
- `script/parse-agentica-repo.sh`: checks the interpreter repository against this grammar.
- `ast-grep/`: ast-grep project configuration and example rules.

## Check the Agentica interpreter repository

The integration script parses every `.agc` file in `examples/`, `stdlib/`, `tests/fixtures/`, and `tests/bdd/` in the [Agentica repository](https://github.com/sonic182/agentica). It also parses every `agentica` code block in `site/content/`.

```sh
script/parse-agentica-repo.sh [path]
```

The path defaults to `~/apps/agentica`; set `AGENTICA_REPO` to use another checkout. The script fails on any `ERROR` or `MISSING` node. It skips fixtures that are intentionally invalid: those whose `.expected` golden, or whose module fixture's `.linked` golden, starts with an `ERROR LEX-` or `ERROR PARSE-` line.
